# UnitHub for the web

A study planner for units, deadlines and grades: the Windows (and any-browser) version of the UnitHub Mac app.
**Made by Michal · Michal Tech.**

- Works in any modern browser. In Microsoft Edge, click **Install** in the address bar to get it as an app with its own window and taskbar icon.
- Works offline, and updates itself when a new version is published.
- Units and tasks can live **in this browser** (no account needed) or come read-only from `tracker/tasks.json` files in your own GitHub repos.
- Nine skins (Netrunner, Arasaka, Maelstrom, Sonder, Mochi, Ledger, Grove, Skyglass, Pixel Quest), each with its own themes, animations and synthesised sounds.

Your data stays in your browser. Use **Settings → Backup** now and then.

## Running it locally

```
python3 -m http.server 8642
```

then open http://localhost:8642.
